# Live-data checklist

Before every fresh USD/RUB exit-timing update:

- [ ] Current date/time and days remaining to deadline
- [ ] CBR official USD/RUB
- [ ] Market proxy / futures / CNY confirmation
- [ ] CBR rate and latest guidance
- [ ] Russian weekly/monthly inflation
- [ ] Russian inflation expectations
- [ ] Budget deficit
- [ ] Oil-and-gas revenues
- [ ] Ministry of Finance FX operations
- [ ] Next tax-payment date
- [ ] Brent
- [ ] Urals / Russian realized-price proxy
- [ ] Crude export volume
- [ ] Diesel/product export volume
- [ ] Refinery outages
- [ ] Port/pipeline/terminal disruptions
- [ ] Sanctions / waivers / payment restrictions
- [ ] Russia-Ukraine negotiation status
- [ ] Front/infrastructure changes relevant to energy exports
- [ ] Fed rate and guidance
- [ ] DXY / broad USD
- [ ] US CPI/PCE/payrolls
- [ ] FOMC / CBR dates before deadline
- [ ] Probability of 91/93/95/100 touch
- [ ] Primary local-maximum window
- [ ] Decision: wait / start selling / sell most
