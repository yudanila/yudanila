# BIM/CAD Automation Developer

I build practical tools for BIM/CAD automation, engineering data processing and AI-assisted 3D workflows.

My current focus is on plugins and prototypes for Revit, nanoCAD, Model Studio, IFC, SAT/STEP conversion and BIM parameter analysis.

## Main areas

* BIM/CAD automation
* Revit API development
* nanoCAD and Model Studio workflows
* IFC, SAT and STEP data exchange
* BIM parameter mapping and analysis
* AI-assisted engineering and 3D workflows

## Tech stack

* C#
* .NET Framework
* Revit API
* nanoCAD API
* Model Studio CS
* IFC
* SAT / STEP
* Excel-based parameter mapping
* Python for data processing and CAD experiments
